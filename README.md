# A Birthday Surprise ❤️

A premium, mobile-first birthday surprise website — a personalized digital love letter with funny interactions, a romantic letter, and a playful yes/no finale.

## Personalize

Edit names in [`src/config.ts`](src/config.ts):

```ts
export const GIRL_NAME = 'Radhika'
export const BOY_NAME = 'Pratik Khunt'
```

Optional music: add `public/music/vibe.mp3`, then use **Play our vibe**.

## Run

```bash
npm install
npm run dev
```

Open on your phone (same Wi‑Fi) using the local network URL Vite prints, or use Chrome DevTools device mode (360 / 390 / 412 / 430).

## Build

```bash
npm run build
npm run preview
```

## Stack

React · Vite · Tailwind CSS · Framer Motion · Lucide
